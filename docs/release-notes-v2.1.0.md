# 年会与婚礼抽奖 v2.1.0 发布说明

本次 `v2.1.0` 针对用户在 `v2.0.0` 试用中提出的 **6 项视觉质感与交互体验反馈** 进行了全面升级，同时完整包含 `v2.0.0` 的全部百人防闪烁、结果一致性与跨平台能力。

---

## 🌟 v2.1.0 重点更新（回应最新试用反馈）

1. **还原并升级 1.2.2 精致名片质感 + 3D 星空氛围粒子**：
   - 修复 `2.0.0` 中文字卡片退化为直角纯色方块的问题：重新加入 **24px 圆角矩形裁剪**、**对角高光渐变叠加**、**半透明精致圆角描边**、**顶部工号胶囊标签**、**主次字号自适应分层（姓名突出、部门柔和）** 与 **底部装饰线**；照片卡片底部同步采用柔和渐变遮罩。
   - 恢复 3D 场景中央的 **发光核心球** 与 **180 颗环绕旋转的星空背景粒子**，同时保持 `alphaTest` 与单卡单纹理复用，兼顾高颜值与零闪烁。
2. **修复“按下停止（抽取中...）立刻静态剧透中奖名单”问题，实现丝滑减速聚焦动效**：
   - **修复前（`2.0.0`）**：按下“停止”瞬间即把 `winners` 传入 3D 场景并切换为静态横排，导致按钮显示“抽取中...”时中奖名单已经提前亮在屏幕上，毫无减速悬念。
   - **修复后（`2.1.0`）**：按下“停止”进入“抽取中...”阶段时，3D 球体/矩阵保持全员卡片并**平滑阻尼减速**（绝不提前剧透）；待减速完成后，中奖者的卡片直接从球体所在位置**发光放大并平滑飞向镜头中央聚焦定格**，其余背景卡片柔和退后半透明化，随后无缝弹出中奖弹窗。
3. **支持 3D 球体与名片尺寸自由缩放 + 全屏视野铺满**：
   - 3D 渲染画布由原先的局部区域扩展为**全屏铺满（`inset-0`）**，彻底解决球体偏小、人多挤成一团的问题。
   - 在「外观设置」与抽奖页顶部 **「动效与尺寸」** 快捷菜单中新增 **`70%–200%` 尺寸缩放滑块** 及 **紧凑 / 标准 / 大屏 / 巨幕** 快捷档位，全屏投屏时视觉冲击力大幅提升。
4. **新增 4 种 3D 抽奖动效形式（可在抽奖页随时切换）**：
   - **🌐 经典球体（Sphere）**：黄金螺旋球面环绕旋转；
   - **🪐 螺旋星环（Helix）**：多层立体圆柱螺旋环绕穿梭；
   - **🌌 全屏漫游（Starfield）**：卡片在全屏 3D 空间内自由飞舞穿梭；
   - **💻 矩阵数据雨（Matrix Rain）**：卡片分列从大屏上方如黑客帝国数据雨般交错下落滚动。
5. **「外观设置 - 显示选项」新增实时名片预览图**：
   - 在「外观设置 → 显示选项与 3D 场景效果」右侧新增 **🪪 抽奖名片实时预览**（双画布同时展示“文字名片效果”与“带照片名片效果”），与 3D 场景共用同一套绘制函数，勾选/取消照片、姓名、工号、部门或切换主题时所见即所得。

---

## 🔧 完整包含 v2.0 核心能力（Fixes #2）

- **百人以上照片零闪烁**：每张卡片固定绑定并复用单张 `CanvasTexture`，卸载时自动 `dispose()`；180 人内同屏呈现，超 180 人每 8 秒顺序轮播翻页，全员参与实际抽取。
- **工号非必填 & 婚礼/纯号码预设**：姓名或工号至少填一项即可导入；提供「只显示姓名」「只显示号码」「全部显示」一键预设，同时作用于 3D 场景、中奖弹窗、轮盘与终极大奖。
- **一键投大屏 & 跨电脑配置迁移**：顶部「投大屏」一键将窗口移至外接扩展屏并全屏；「💾 配置迁移」支持将全套名单、照片、奖项、背景、音乐、3D 动效与尺寸设置打包导出为单个 `.json` 文件跨电脑恢复。
- **隐蔽的高级概率与定向设置**：抽奖页待机状态下连点右下角「可抽奖人数」5 次唤出，抽奖开始即自动关闭，大屏全程零暴露。
