# 年会与婚礼抽奖 v2.0.0 发布说明

## 核心修复：百人以上头像闪烁与结果一致性（Fixes #2）

- **彻底修复 > 60 人（如 100 / 150 人）带照片滚动时快速闪烁、消失与跳位（[Issue #2](https://github.com/ScryAbu/Annual-Lucky-Draw/issues/2)）**：
  - **根因**：1.x 版本在抽奖 Hook 中每 100ms 触发一次全量状态重渲染，`LotteryPage` 每次返回新的可用池数组引用，导致 `LotterySphere` 在人数超过 60 人时每秒执行 10 次随机重排与截取（`sort + slice(0, 60)`），卡片组件被反复卸载与挂载；同时照片卡片在异步解码完成前返回 `null`，直接造成画面高频闪现与纹理泄漏。
  - **修复**：移除无效高频状态更新并固定本轮抽奖名单引用；3D 球体改为面向相机的不透明 `Sprite`，每张卡片绑定并复用单张 `CanvasTexture`（照片加载前先绘制文字底卡，加载完成后绘制到同一画布，组件卸载时取消回调并 `dispose()` 释放显存）。
- **修复抽奖定格动画与弹窗实际中奖人不一致**：
  - 点击“开始”时即冻结本轮符合资格的人员池；点击“停止”或按空格键时仅执行一次抽取，通过 Dexie 事务原子写入人员表与奖项表后，3D 球体定格展示与随后弹出的中奖名单完全复用同一组结果。若数据库写入异常则回退且不错误揭晓。
- **修复少人数（如 1–3 人）球体上下卡片只微颤不转动**：
  - 球面坐标纵轴分布由 `i / (count - 1)` 改为半步偏移 `(i + 0.5) / count`，避开旋转轴南北两极并消除 1 人时的除零问题，确保少量人员时所有卡片均围绕球心完整旋转。

## 新增功能与体验优化（回应 B 站与 GitHub 用户反馈）

- **大名单顺序轮播与全员参抽**：
  - `180` 人以内同屏完整呈现；超过 `180` 人时每 `8` 秒按固定顺序自动翻页展示，既控制 GPU 显存占用，又保证每位参与者都能在大屏出现。**分页仅影响视觉展示，全体符合资格的人员始终参与实际抽取**。
- **工号非必填、支持婚礼纯姓名与入场券纯号码抽奖**：
  - Excel 导入与手动添加人员均只要求**“姓名”或“工号/号码”至少填一项**。
  - 无工号人员自动分配如 `N000001` 的独立编号，同名人员不会合并；支持保留 Excel 文本或 `0000` 格式的前导零。
  - 3D 球体卡片直接显示真实工号/号码，不再显示误导性的渲染下标。
- **全局统一的显示字段开关与预设**：
  - 在「外观设置 → 显示选项」中提供 **照片、姓名、工号/号码、部门** 四个独立开关，以及 **「只显示姓名」**（婚礼场景）、**「只显示号码」**（纯序号场景）快捷预设。
  - 设置同时作用于 **3D 球体卡片、常规中奖弹窗、轮盘抽奖、终极大奖**，彻底解决中奖界面关不掉工号或部门的问题。
- **球体旋转速度可调**：
  - 在「外观设置」新增旋转速度滑块（`0.5–6.0` 弧度/秒），按真实帧间隔（delta time）平滑阻尼加速与减速。
- **一键投大屏**：
  - 抽奖页顶部新增 **「投大屏」** 按钮，可列出系统已连接的扩展显示器，一键将当前抽奖窗口移至目标屏幕并进入全屏。
- **完整配置导出与跨电脑搬家**：
  - 新增 **「💾 配置迁移」** 页面，支持将名单、裁剪头像、奖项、奖品图片、中奖记录、主题、自定义背景、Logo、背景音乐及高级设置打包导出为单个 `.json` 文件（上限 `100 MB`），在另一台电脑校验导入；若校验失败或空间不足则自动回退，保护现有数据。
- **隐蔽的高级概率与定向设置（抽奖大屏零暴露）**：
  - 员工编辑支持设置 `1–100` 的优先级系数（Excel 支持 `权重 / weight` 列），默认保持等概率均匀抽取。
  - 在常规抽奖页**待机状态**下，连续点击右下角 **「可抽奖人数」** 卡片 **5 次** 可打开隐蔽的「⚙ 高级设置」面板，切换 `标准均匀 / 系数加权` 采样模式或配置定向分配；一旦开始滚动抽奖，面板自动关闭且不可唤出，大屏全程不显示任何概率或内定字样。
- **交互与数据安全加固**：
  - 空格键快捷抽取严格遵循当前选择的“本次抽取人数”（`1–30` 人）。
  - 增加开始/停止同步状态锁，防止连击或连按空格导致重复抽取。
  - 返场抽奖允许往轮中奖者参与，但同一奖项内绝不重复中奖；历史记录完整保留返场中奖明细；覆盖或删除已关联奖项的中奖人员前强制要求先清理抽奖记录。

## 数据迁移与升级注意事项

1. **升级前请先备份**：虽然 2.0 保留了对 1.x 本地存储设置的兼容迁移逻辑，但在覆盖安装前，建议先在旧版导出员工名单与中奖结果 Excel。
2. **跨电脑请用「配置迁移」**：人员与奖项保存在本机 IndexedDB，直接拷贝安装包（`.exe / .dmg`）不会带走任何设置。换电脑请在「配置迁移」页面导出 `.json` 并在新电脑导入。
3. **未签名构建提示**：Windows 与 macOS 安装包暂未配置商业代码签名与 Apple 公证。首次打开若遇系统安全拦截，Windows 请点“更多信息 → 仍要运行”，macOS 请在“系统设置 → 隐私与安全性”中允许打开。
4. **验证边界说明**：本次发布已完成 TypeScript 类型检查、28 项单元与 3D 场景回归测试、本机 Chrome 150 张合成照片 WebGL 纹理稳定性实测与 Windows 解包程序隔离启动验证（详见 [`docs/lottery-2-validation.md`](lottery-2-validation.md)）。物理多屏外接环境与 macOS 实机安装请在正式活动前于现场设备先行演练。
